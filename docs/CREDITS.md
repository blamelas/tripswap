# Créditos das imagens

Todas as fotografias foram descarregadas para `public/images/` e convertidas para WebP
(1600 px de largura, qualidade 82), para que a demonstração funcione sem rede externa.
Nenhuma imagem é servida a partir de um domínio de terceiros em runtime.
